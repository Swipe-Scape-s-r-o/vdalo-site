1. Збережіть поточну версію контенту. Матеріали цього пакета є редакційною підготовкою, не опублікованими змінами.

3. Переносьте 16 статей і 6 кейсів разом із метаданими та пов’язаними картками блогу, авторів і кейсів. Не повертайте старий заголовок на картку після зміни сторінки.
4. Збережіть URL. Для чотирьох відомих дублів використовуйте canonical-адреси у внутрішніх посиланнях. Редиректи потребують перевірки роутингу, а не автоматичного додавання.
5. Для головної та сервісних сторінок перенесіть текстові блоки й CTA. Функціональність форм, калькуляторів, оплати та каталог модулів цим завданням не змінена.
6. Для 28 локальних довідок перенесіть джерела й специфічні умови. Перш ніж змінювати ставки самого калькулятора, звірте місцеві акти. Окремі залежності відкриті для Одеси, Яремчі, Києва й Житомира, а також для спірних цінових меж.
7. На юридичних сторінках запропоновано редакційне оформлення без нових істотних умов. Не підміняйте реальний реєстр обробки даних припущеннями. Для email-звіту потрібна фактична перевірка передачі.
8. Упроваджуйте JSON-LD з каталогу як чернетку: додайте реальні дати й зображення, лише якщо вони відповідають фінальній сторінці. Не ставте сьогоднішню дату як дату публікації старої статті. Перевірте Rich Results Test та Schema Validator після впровадження. Зовнішні валідатори в цьому завданні не запускалися.
9. Після перенесення перевірте HTML, мобільну читабельність таблиць, один H1, canonical, збережені noindex та переходи CTA. Перевірте реальні успішні й помилкові стани форм у погодженому середовищі, без випадкових оплат.
