# Доробка дизайну нижніх блоків 13 лендосів

## Завдання власника

Залишити композицію заголовків на desktop, додатково оформити нижні секції, додати доречні іконки й перевірити результат на desktop/mobile. Спочатку staging, основний домен після перегляду оновленого staging.

## Спостереження та зміни

| Спостереження | Що дороблено |
|---|---|
| Переваги й наступні кроки позначені однаковими номерами | Для переваг створені тематичні SVG-іконки; нумерація залишена для послідовності кроків |
| Переваги виглядають як окремі текстові колонки | Додано цілісні картки з м’якою поверхнею, рамкою та узгодженими відступами |
| Послідовність після заявки слабко пов’язана візуально | Додано іконки розмови, налаштувань і календаря та стрілки між трьома кроками |
| FAQ і завершальна пропозиція потребують акцентів | Додано піктограму FAQ, обрамлення індикаторів розкриття, оформлення фінальної пропозиції |
| Світлий фон потребує виразного клавіатурного фокуса | На світлій частині використано темніший контур; у темному фінальному блоці — рожевий |

Іконки відповідають змісту кожного з 13 лендосів: календар/канали, анкета/документи, туристичний збір, база відповідей, пряме бронювання, прибирання, команда й пізній заїзд. SVG декоративні, приховані від допоміжних технологій, не додають зовнішніх запитів чи бібліотек. Статичні картки не імітують кнопки.

Тексти H1, композиція hero, форми, маршрути, CRM, ціни, налаштування аналітики та механіка /q3 без калькулятора не змінювалися.

## Перевірки

- 170 наявних автоматизованих тестів пройшли після змін.
- `git diff --check`: без помилок.
- Перед початком GitHub main: 32def9c; staging: 2201e1f. Сторонніх відстежуваних змін у робочій гілці не було.
- Браузерне підключення відновлено. Фінальний коміт дизайну 3fd66c8 передано в staging, нові SVG та CSS `20261023c` підтверджено на живому сайті.
- На staging перевірено всі 13 маршрутів на фактичних 1440/768/390/320 CSS px: 52 перевірки. Межі блоків і текст не переповнюють екран, кожна сторінка має три тематичні іконки, декоративні SVG приховані від допоміжних технологій.
- На кожному маршруті верхня й нижня CTA відкрили контактну форму, FAQ розкрився й закрився клавіатурою. Заявки не надсилалися. Код форми й аналітики цією доробкою не змінювався.
- У зібраних console error/warn помилок не знайдено. Складений звіт: docs/design-references/oct23-polish/staging-qa.json. Збережено 14 успішних скриншотів нижніх блоків; окремі спроби desktop-скриншотів завершувалися таймаутом інструмента, тому їх не зараховано як збережені докази. Фінальний desktop/mobile /q2: staging-q2-1440.jpg та staging-q2-390.jpg.
- Декоративні стрілки між кроками виконано CSS-геометрією, щоб вони не озвучувалися екранними читачами.
- Viewport Chrome не замінює фізичний телефон, екранну клавіатуру та інші браузери.
