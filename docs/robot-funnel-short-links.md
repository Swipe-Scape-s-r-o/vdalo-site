# Короткі посилання для SMS-воронок

Усі активні посилання мають не більше двох символів після останнього `/`.

| Короткий маршрут | Внутрішній код | Сторінка |
|---|---|---|
| `/q1` | `q1` | Подвійне бронювання |
| `/q2` | `q2` | Дані гостей |
| `/q3` | `q3` | Туристичний збір |
| `/q4` | `q4` | Часті питання гостей |
| `/q5` | `q5` | Нічні запитання |
| `/q6` | `q6` | Бронювання в зошиті |
| `/q7` | `q7` | Комісія Booking |
| `/q8` | `q8` | Прибирання номерів |
| `/q9` | `q9` | Навантаження на команду |
| `/qa` | `q1b` | Альтернативна сторінка про подвійне бронювання |
| `/qb` | `q4b` | Альтернативна сторінка про питання гостей |
| `/qc` | `q7b` | Прямі бронювання |
| `/qd` | `q10` | Пізній заїзд |

Внутрішні коди збережені, щоб не змінювати відеоманіфест, CRM-атрибуцію та звіти. Старі публічні маршрути `/q1b`, `/q4b`, `/q7b` і `/q10` перенаправляються на короткі варіанти та зберігають query-параметри кампанії. Нові SMS мають використовувати тільки короткі маршрути.
