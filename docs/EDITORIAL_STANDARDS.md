# Редакційні стандарти VDALO

## Тире

Погоджено власником 24 жовтня 2026. Діє для всіх публічних текстів VDALO.

1. Довге тире Unicode U+2014 не використовуємо.
2. Коли тире потрібне за змістом, використовуємо коротке U+2013. У реченні відокремлюємо його пробілами, у числовому діапазоні застосовуємо правила відповідного контексту.
3. За можливості пишемо простіші речення з крапкою, комою, двокрапкою чи дужками.
4. Правило поширюється на статті, кейси, інтерфейс, заголовки, CTA, alt, підписи, title, description, Open Graph, JSON-LD та текст усередині графіки.
5. HTML-сутності й CSS-коди, які відображають U+2014, також заборонені в публічному тексті.
6. Перед додаванням або оновленням матеріалу перевіряємо його вихідний текст і відображення. Фіксуємо, які сторінки вже очищені, без твердження, що весь старий сайт очищений автоматично.
7. URL, програмні оператори, ідентифікатори та незмінені архівні докази не переписуємо як редакційний текст.

Цей документ є постійним джерелом редакційного правила для подальших робіт.
