МІНІМАЛЬНИЙ ФАЙЛ ДЛЯ СТРУКТУРНОЇ ПЕРЕВІРКИ
Потрібні тільки: внутрішній код бронювання, код фізичного номера, дати, стан, валюта й сума.

Перед вибором файлу:
1. Зробіть окрему копію експорту.
2. Приберіть ім’я, email, телефон, адресу гостя та документи.
3. Приберіть дані картки, платіжні токени, паролі й коди доступу.
4. Замініть ідентифікатор синтетичним кодом, якщо оригінальний може розкривати гостя.
5. Перевірте, що інші колонки й коментарі також не містять цих даних.
6. Залиште одну явну валюту для однієї перевірки, без перерахунку курсу.


Зберігайте підготовлену копію у погодженому робочому місці. Для фактичного перенесення потрібні узгоджений формат системи, доступи та пробна звірка.
